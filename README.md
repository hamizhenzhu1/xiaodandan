# 栖页 LinkHaven

一个简洁、私密的个人网址导航站。网址、分类和主题设置只保存在当前浏览器，支持搜索、拖拽排序以及 JSON 备份恢复。

## 本地开发

```bash
pnpm install
pnpm dev
```

## 验证

```bash
pnpm lint
pnpm test
pnpm build
pnpm test:e2e
pnpm format:check
```

详细产品要求见 [PRODUCT_DESIGN.md](./PRODUCT_DESIGN.md)，技术方案见 [docs/TECHNICAL_DESIGN.md](./docs/TECHNICAL_DESIGN.md)。
